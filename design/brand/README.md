# Sericant wordmark

Production: public/images/sericant-logo.svg and app/components/SericantLogo.tsx use identical outlined Inter letterforms; no font loading is required. PNG is rendered from the same outlined SVG at 2240 × 520 with transparency.

Source: https://github.com/google/fonts/tree/main/ofl/inter
Inter variable font: weight 800, optical size 32. Tracking: -0.04 em. Outlines scaled uniformly into the existing 112 × 26 canvas. Site typography and logo CSS dimensions are unchanged.

Inter is licensed under SIL OFL 1.1; see Inter-OFL.txt. Editable SVG requires Inter installed and is an editing aid, not the production artwork. The path files are authoritative for final geometry.
